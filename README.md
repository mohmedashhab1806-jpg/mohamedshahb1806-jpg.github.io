# لوحة Miga Life — ملفات GitHub Pages

هذه نسخة ثابتة من الواجهة؛ لا تتصل بخادم أو قاعدة بيانات. أي إضافة أو تعديل يُحفظ داخل `localStorage` في المتصفح الحالي فقط، ولا يصل إلى بقية أعضاء الإدارة أو إلى جهاز آخر.

> **تنبيه:** GitHub Pages يستضيف ملفات عامة ولا يوفر تسجيل دخول أو صلاحيات محمية. نسخة الواجهة هذه للعرض والتجربة ببيانات غير حساسة فقط. لا تضع فيها كلمات مرور أو معلومات أعضاء حقيقية أو سجلات خاصة؛ صلاحيات الواجهة قابلة للتجاوز من المتصفح.

## الملفات

- `index.html` — الصفحة الرئيسية، موجودة في جذر الموقع.
- `dashboard.css` — التصميم المتجاوب.
- `dashboard.js` — تفاعلات الواجهة وحفظ بيانات التجربة محلياً.
- `logo.gif` — شعار الموقع.
- `.nojekyll` — يمنع GitHub Pages من تجاهل الملفات التي تبدأ بنقطة.

## النشر على GitHub Pages

1. فك ضغط الملف ZIP على جهازك.
2. افتح المستودع المطلوب في GitHub، واضغط **Add file → Upload files** أو **uploading an existing file**.
3. ارفع الملفات والمجلدات التي ظهرت بعد فك الضغط، بحيث يكون `index.html` في جذر المستودع. لا ترفع ملف ZIP وحده.
4. اضغط **Commit changes**.
5. افتح **Settings → Pages**.
6. في **Build and deployment** اختر **Deploy from a branch**، ثم اختر الفرع `main` والمجلد `/ (root)` واضغط **Save**.
7. انتظر اكتمال النشر، ثم افتح الرابط الذي يظهر في صفحة Pages.

لتجربة الواجهة قبل الرفع، افتح `index.html` مباشرة في المتصفح. امسح بيانات النسخة من إعدادات الموقع في المتصفح بحذف بيانات التخزين المحلي للموقع.
